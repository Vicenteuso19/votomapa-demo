# VotoMapa Chile · Comparador ciudadano

**Abrir el demo:** https://vicenteuso19.github.io/votomapa-demo/

Doce votaciones reales y reñidas de la Cámara de Diputadas y Diputados de Chile
(periodo 2026–2030): marcas cómo habrías votado y te muestra con qué diputados y
coaliciones coincides, y dónde quedas en el mapa de la Cámara.

Es un solo archivo HTML: todo se calcula en el navegador y tus respuestas no salen
de él. Datos: API abierta de la Cámara de Diputadas y Diputados.

Proyecto del curso IIC2433 Minería de Datos, 2026. Este repositorio solo publica el
demo; lo genera `src/demo_build.py` del repositorio del proyecto.
